# iamcheyan.active-window

Native Omarchy top bar widget displaying active window title and icon, or OS distro logo and version on empty desktop, with window action menu.

## Features

- **Active Window Status**: Shows focused window's application icon and title with graceful eliding.
- **Empty Desktop Status**: Shows the system Linux distribution icon (NixOS, Arch, Fedora, Ubuntu, Debian, etc.) and version number when on empty desktop.
- **Action Menu**: Click to open a quick context menu for the target window (Toggle Floating, Fullscreen, Pop Out, Scratchpad, Close, Force Quit).
- **Quick Close**: Middle-click on the pill closes the active window directly.
